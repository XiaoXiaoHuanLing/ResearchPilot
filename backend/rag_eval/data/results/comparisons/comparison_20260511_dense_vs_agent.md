## 二、分类型详细对比

### 2.1 Keyword型 (n=39)

| 指标 | Dense | Agent | Δ |
|------|-------|-------|---|
| CP | 0.417 | 0.608 | +0.191 |
| CR | 0.375 | 0.782 | **+0.407** |
| Faith | null | 0.746 | — |

**提升原因**: 
- Keyword型问题检索关键词明确但可能分散在多个文档中
- Dense单轮检索只能匹配一次语义空间，关键词不精确时召回率低（CR=0.375）
- Agent通过ReAct多轮检索，可以先搜索宽泛关键词→精确定位→补充检索，将CR从37.5%提升到78.2%（+40.7个百分点）
- CP从0.417→0.608：Reranker重排提升了相关性排序

### 2.2 Fact型 (n=29)

| 指标 | Dense | Agent | Δ |
|------|-------|-------|---|
| CP | 0.708 | 0.896 | **+0.188** |
| CR | 1.000 | 1.000 | ±0.000 |
| Faith | 0.600 | 0.799 | +0.199 |

**提升原因**:
- Fact型问题直接查找特定事实，Dense的CR已经完美（1.0），说明向量检索足以定位
- 但Dense返回的top_k中夹杂无关片段，CP只有0.708 → Agent的Reranker将相关片段排到前面，CP提升至0.896
- Faithfulness提升（0.600→0.799）：Agent的蒸馏式prompt（先输出事实点再生成答案）减少了无关信息的混入

## 四、核心结论

### Agent为什么优于Dense？

1. **多轮检索（ReAct）**: Agent可分解查询 → 初步检索 → 发现不足 → 补充检索，单轮Dense无法做到
2. **Reranker重排**: Agent在检索后调用rerank_recall_pool，用CrossEncoder重排，提升排序质量
3. **蒸馏式Prompt**: Agent先输出事实点再生成答案，减少幻觉，提升Faithfulness
4. **动态调整**: Agent可根据第一次检索结果调整策略（如换关键词、扩大范围）

### Dense哪里仍有优势？

1. **速度快**: RAG耗时 2473s vs Agent 4792s，Dense快近1倍
2. **特定类型精度高**: Negation型CR=1.0（Dense完美），Vague型CP=1.0（虽然CR极低）
3. **简单直接**: 无需Agent调度开销，适合对延迟敏感的场景

### 待改进

1. **Factual Correctness始终null**: RAGAS的FC指标与当前评估模型不兼容，需排查
2. **Hard题CP=0**: 7条样本太少，排序质量差，需要更多Hard题或改进Reranker
3. **Medium题CP略降**: Agent多召回引入噪声，可用更高阈值的Reranker过滤
