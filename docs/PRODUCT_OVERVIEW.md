# ResearchPilot 产品定义

## 定位
面向公开专题研究的 AI 助手平台：主动追踪 · 知识沉淀 · 问答分析 · 报告生成

## 核心理念
- **主动获取**：专题定时采集 + 智能对话式搜索 + 手动URL采集
- **知识沉淀**：收藏资讯自动入向量库 + 用户上传文档入知识库
- **智能问答**：RAG检索+联网搜索+LLM生成，三种模式可选
- **报告输出**：选文章+提示词，LLM生成结构化研究报告

## 使用场景
- 追踪舰船/武器/军事技术公开动态
- 构建个人研究知识库
- 生成专题研究简报
- 快速检索已积累的研究资料

## 资讯获取方式

| 方式 | 类型 | 说明 |
|------|------|------|
| 专题定时采集 | 主动/自动 | APScheduler 按调度自动搜索入库 |
| 手动采集URL | 主动/手动 | 用户给URL → 抓取入库 |
| 专题一键采集 | 主动/手动 | 点按钮 → 搜索+抓取 |
| 智能对话搜索 | 被动/按需 | 用户问问题 → 自动判断联网 → 搜索+入库+综合回答 |

## 知识库体系

| 知识库类型 | 来源 | 向量库标识 |
|-----------|------|-----------|
| 收藏资讯知识库 | 收藏文章自动入库 | kb_type=bookmarks, kb_id=默认KB的ID |
| 用户创建知识库 | 手动上传文本/文件 | kb_type=upload, kb_id=KB_ID |

## 智能对话模式

| 模式 | 说明 |
|------|------|
| 混合智能（默认） | 先查知识库，不足时自动联网搜索，综合回答 |
| 联网搜索 | 纯互联网搜索，获取最新信息 |
| 知识库问答 | 仅基于已收藏/上传文档，可选指定知识库 |

## 约束
- 仅公开、非涉密信息
- 强调来源可溯性和可信度
- 专题聚焦式研究工作流
